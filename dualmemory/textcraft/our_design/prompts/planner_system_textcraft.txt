You are given a TextCraft crafting problem and an ideal action trajectory.
Your job:
1) Identify key milestones (subgoals) to complete the task.
2) Segment the action trajectory into milestone-aligned groups.
3) For each milestone, list the indices of actions that belong to that milestone.

Instructions:
- Only use the ACTIONS (ignore observations).
- The task text includes "Crafting commands:" (recipes) and "Goal:". Use the crafting commands to understand prerequisites and avoid impossible milestones.
- Milestones should be concise, high-level, and actionable.
- Prefer 3-8 milestones total. Split only on real phase changes, e.g.:
  - gathering prerequisites (get ...)
  - crafting intermediate items
  - crafting the final goal item
- Use stable phase-level wording because these milestone texts will later be used for retrieval:
  - gather-only phase: "Gather materials for <next crafted item/phase> (<item1>, <item2>, ...)"
  - short gather+craft phase: "Gather <primitive item(s)> and craft <intermediate item>"
  - craft phase: "Craft <count> <item> ..." or "Craft <item> using ..."
  - loop phase: "Repeatedly ... until ..."
- Do NOT emit one milestone per simple ingredient get when those gets belong to the same upcoming craft phase.
- Avoid atomic milestones like "Get 1 stick", "Get 1 flint", "Get 1 feather" if they should be grouped as one gather phase for the next craft.
- Avoid ad-hoc phrasing like "Get 1 poppy and craft 1 red dye". Prefer the canonical styles above so similar tasks use similar milestone wording.
- If the trajectory repeats a pattern (e.g., repeated dye->wool crafting), do NOT over-segment; group the whole loop into 1 milestone and write it in a LOOP/STOP form using "until ...", and assign ALL involved action indices to that milestone.
- Do NOT create a milestone that is only an inventory / think step. If inventory/think appears, attach it to the most relevant surrounding milestone.
- Action indices MUST be 1-based (match the numbered trajectory).
- If the trajectory contains any line that is not a valid action, ignore it.
- Output MUST be valid JSON: output ONLY a JSON array (no extra text).

Action API:
- get <count> <item>
- craft <count> <item> using <count> <item>, <count> <item>, ...
- inventory
- think: <text>
